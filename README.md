## ⚡ Features

This project is built with a **Neo-Brutalist** design system (Cream, Ink Black, and Safety Orange) and is fully responsive.

*   🐍 **The Seven Python Book (`python.html`):** A complete 26-chapter manual from basics to advanced Python, complete with copyable code blocks.
*   💻 **Interactive Python Terminal:** A real Python 3.12 environment running directly in the browser using **Pyodide (WebAssembly)**. Users can write and execute Python code in real-time.
*   🛠️ **Cyber Toolkit:** Client-side utilities for developers and security analysts:
    *   Password Generator
    *   Base64 Encoder / Decoder
    *   SHA-256 Hash Generator
*   📚 **Core Modules (`modules.html`):** Documentation and scripts for:
    *   Task Automation (File organizers, Web Scraping)
    *   Network Defense (Port Scanners, Firewall concepts)
    *   Offensive Security (Ethical hacking scripts)
    *   Cryptography (Fernet Encryption, Hashing)
    *   OSINT (IP Geolocation, WHOIS Lookup)
*   🌙 **Dark Mode:** Synced across the hub and the Python book.

## 📂 Project Structure

Since this is a fully static website, there is no build step or backend required. 

    Se7en-books/
    │
    ├── index.html          # Main landing page (Neo-Brutalist UI, Terminal, Toolkit)
    ├── python.html         # The Seven Python Book (Documentation layout)
    ├── modules.html        # Core Modules (Tabbed SPA layout for learning materials)
    ├── README.md           # This file
    └── assets/             # (Optional) Images or additional CSS/JS files

## 🚀 How to Run Locally

1. Clone the repository:
   git clone https://github.com/seven25-ui/Se7en-books.git

2. Navigate to the folder:
   cd Se7en-books

3. Open the website: 
   Simply double-click `index.html` to open it in your browser. 
   *(Tip: If you are using VS Code, use the "Live Server" extension for hot-reloading).*
