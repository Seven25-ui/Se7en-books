Preface

This book teaches Python through seven progressive parts, each building on the last. It assumes no prior programming experience but rewards patience. By the end, you will be able to write real programs, understand the language deeply, and know where to go next.

Work through the parts in order. Type the code yourself — do not copy-paste. Muscle memory matters. When something confuses you, do not skip it; confusion is the feeling of learning.

"The only way to learn a language is to speak it badly until you speak it well."

Part One — First Steps

1. What Python Is

Python is a programming language created by Guido van Rossum in 1991. It is named after Monty Python, not the snake. It emphasizes readability: code should look like pseudocode that happens to run.

Python is interpreted — a program reads and executes it line by line. It is dynamically typed — you do not declare variable types. It is high-level — you do not manage memory manually.

You will find Python in web servers, data science, automation, games, machine learning, and education.

2. Installing Python

Go to python.org and download the latest stable version (3.12 or newer). On Windows, check “Add Python to PATH.” Verify:

python --version
# Python 3.12.3

You also get pip, the package installer. For serious work, install VS Code with the Python extension.

3. Your First Program

Create hello.py:

print("Hello, world!")

Run with python hello.py. print() is a function; the text is an argument; the quotes mark a string.

print("Python is fun.")
print(2 + 2)
print("2 + 2 =", 2 + 2)

8. Conditionals

age = int(input("How old are you? "))

if age < 13:
    print("Child")
elif age < 20:
    print("Teenager")
elif age < 65:
    print("Adult")
else:
    print("Senior")

Ternary: status = "adult" if age >= 18 else "minor". Empty values ("", [], 0, None) are falsy.

Part Four — Objects and Errors

14. Classes and Objects

class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        return f"{self.name} says woof!"

    def __str__(self):
        return f"Dog({self.name}, {self.age})"

rex = Dog("Rex", 3)
print(rex.bark())   # Rex says woof!
print(rex)          # Dog(Rex, 3)

class Puppy(Dog):
    def bark(self):
        return f"{self.name} says yip!"

21. A Command-Line Tool

# wordcount.py
import sys

def main():
    if len(sys.argv) != 2:
        print("Usage: python wordcount.py FILE")
        return
    with open(sys.argv[1], encoding="utf-8") as f:
        text = f.read()
    words = text.split()
    print(f"Words: {len(words)}")

if __name__ == "__main__":
    main()

22. Project — Todo List

import json
import os

FILE = "todo.json"

def load():
    if not os.path.exists(FILE):
        return []
    with open(FILE) as f:
        return json.load(f)

def save(items):
    with open(FILE, "w") as f:
        json.dump(items, f, indent=2)

def show(items):
    for i, item in enumerate(items, 1):
        status = "✓" if item["done"] else " "
        print(f"[{status}] {i}. {item['text']}")

def main():
    items = load()
    while True:
        print()
        show(items)
        cmd = input("add/show/done/quit > ").strip()
        if cmd == "add":
            items.append({"text": input("Text: "), "done": False})
        elif cmd == "done":
            n = int(input("Number: ")) - 1
            if 0 <= n < len(items):
                items[n]["done"] = True
        elif cmd == "quit":
            break
        save(items)

if __name__ == "__main__":
    main()

24. OOP Patterns

from dataclasses import dataclass

@dataclass
class Point:
    x: float
    y: float

class Temperature:
    def __init__(self, celsius):
        self._c = celsius

    @property
    def celsius(self):
        return self._c

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("Below absolute zero")
        self._c = value
